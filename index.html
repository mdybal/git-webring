git-webring

A small, dependency-free webring for personal sites — run from a git repo.

Live demo

The widget below is the <webring> custom element. It's reading members.json from this same repo. On a real member's site, you'd point site at their homepage URL.

Show the HTML 
<script src="https://YOUR-HOST/git-webring/webring.js" defer></script>
<webring site="https://example.com/"></webring>

How to join

  1. Add the two-line widget to your site (see above).
  2. Open a PR adding your entry to members.json:
[
  {
    "id": "your-handle",
    "name": "Your Display Name",
    "url": "https://yoursite.example/",
    "added": "YYYY-MM-DD"
  }
]

Net-new entries go at the bottom. To leave the ring, remove your object in a PR.

Self-hosting

If you'd rather not ping the central registry on every page view, drop the JSON inline:

<script type="application/json" id="webring-members">[ ... paste members.json here ... ]</script>
<script src="/git-webring/webring.js" defer></script>
<webring site="https://yoursite.example/"></webring>

The inline script wins over the network fetch, so you're back to zero external requests.

Why?

Webrings are a thirty-year-old idea worth rescuing: independent sites that link to one another in a ring, surfacing each other to readers. This project reduces the original to its minimum viable form — one JSON file, one script, one custom element — so the cost of joining is roughly fifteen minutes.

Hosted as a regular git repo. Fork, edit members.json, open a PR.
