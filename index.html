RPG Web Ring

Mały, niezależny webring dla polskich stron RPG

Bring back the 90s! Bring back Web 1.0!

Dlaczego to powstaje?

Social media dawno przejęły kontrolę nad tym, co widzimy w sieci. Algorytmy dobierają treści pod kątem kliknięć i reklam, a nie ich wartości dla czytelnika. W efekcie nawet jeśli tworzysz świetną stronę, nikt na nią nie trafi, dopóki algorytm nie zdecyduje inaczej.

Celem tego projektu jest wyrwanie się z tej pętli. Wracamy do pomysłu sprzed trzydziestu lat: niezależnych stron, które ręcznie linkują do siebie nawzajem, tworząc krąg. Czytelnik sam decyduje, dokąd pójdzie dalej — bez feedu, bez cenzury, bez „polecanych dla ciebie”. Zamiast tego mamy po prostu sąsiada w sieci.

Cały projekt jest świadomie śmiesznie mały: jeden plik JSON, jeden skrypt, jeden własny element HTML. Dołączenie zajmuje mniej więcej piętnaście minut — a potem Twoja strona znów jest częścią czegoś większego niż ona sama.

WebRing banner

Poniższy widget to niestandardowy element <git-webring>. Kiedy ktoś otworzy Twoją stronę widget sam pobiera z repozytorium listę innych członków kręgu z pliku members.json.

Kod HTML widgetu, który trzeba dodać na stronie znajdziesz poniżej.

Pokaż kod HTML 
<script src="https://mdybal.github.io/git-webring/webring.js" defer></script>
<git-webring site="https://twojastrona.example/"></git-webring>

Jak dołączyć do kręgu

  1. Umieść widget na swojej stronie. Wklej te dwie linijki w kodzie HTML strony, w miejscu, w którym widget ma się pojawić: 
    <script src="https://mdybal.github.io/git-webring/webring.js" defer></script>
<git-webring site="https://twojastrona.example/"></git-webring>

    Zamień https://twojastrona.example/ na adres swojej strony. Adres musi być dokładnie taki sam jak ten, który potem wpiszesz w members.json.

  2. Dodaj się do rejestru members.json. Na końcu listy dopisz swój obiekt — zachowaj ten sam kształt, co pozostałe wpisy: 
    {
  "id": "twoj-handle",
  "name": "Twoja Nazwa Wyświetlana",
  "url": "https://twojastrona.example/",
  "added": "RRRR-MM-DD",
  "icon": "/avatar.png",               // opcjonalne
  "logo": "/webring-logo.svg"          // opcjonalne
}

    icon to mała miniaturka wyświetlana obok nazwy Twojej strony na paskach nawigacji innych członków. logo to obrazek, który pojawi się w ramce widżetu na Twojej stronie — podaj ścieżkę względną do pliku hostowanego na Twojej stronie.

    Nowe wpisy trafiają zawsze na końcu — w ten sposób naturalnie stajesz obok osoby, która dołączyła tuż przed Tobą. Jeśli chcesz odejść z kręgu, w podobnym PR usuń swój obiekt z listy.

  3. Wyślij Pull Request (PR) na GitHubie. Nie musisz być programistą — wystarczy darmowe konto na GitHubie. Krok po kroku:
    1. Otwórz plik members.json w naszym repozytorium.
    2. Kliknij ikonkę ołówka ✏️ w prawym górnym rogu („Edit this file”).
    3. Na końcu listy dopisz swój obiekt (tak jak w przykładzie wyżej).
    4. Na dole strony kliknij przycisk „Propose changes”.
    5. Na następnej stronie kliknij „Create pull request”.
    6. W tytule PR-a wpisz Add <twoj-handle> to the ring, a w opisie — krótko (jedno zdanie wystarczy), czym jest Twoja strona.

    Ktoś z nas zerknie, czy wszystko się zgadza (adres URL jest taki sam jak w site="" na widżecie, a JSON nadal się parsuje) i najpewniej tego samego tygodnia scalamy Twoje zgłoszenie.

  4. Nie masz konta na GitHubie albo GitHub wydaje się za trudny? Bez stresu — napisz do nas przez profil Twoje Stare RPG na Facebooku. Podaj adres swojej strony, nazwę wyświetlaną i krótki opis, a my sami dopiszemy Twój wpis do kręgu.

Zaawansowana stylizacja (CSS)

Widget udostępnia dwa mechanizmy, które pozwalają wpasować jego wygląd w charakter Twojej strony: zmienne CSS (proste zmiany kolorów i rozmiarów) oraz CSS Shadow Parts (bardziej „chirurgiczne” zmiany poszczególnych elementów).

Zmienne CSS

Wystarczy, że w swoim arkuszu stylów ustawisz jedną lub kilka własności --wbr-* na :root, na body albo bezpośrednio na samym elemencie <git-webring>. Oto przykład:

git-webring {
  --wbr-color: #2b1b10;
  --wbr-bg: #ecdcb8;
  --wbr-accent: #a8420f;
  --wbr-border: #b07a1f;
  --wbr-radius: 4px;
  --wbr-font: "EB Garamond", Georgia, serif;
  --wbr-font-size: 14px;
}

Najczęściej używane zmienne:

  • --wbr-color — kolor tekstu (domyślnie #3a2412).
  • --wbr-bg — tło ramki widgetu (domyślnie #ecdcb8).
  • --wbr-accent — kolor linków (domyślnie #a8420f).
  • --wbr-accent-2 — drugi akcent (podświetlenie, linki odwiedzone).
  • --wbr-border — kolor obramowania (domyślnie #b07a1f, mosiądz).
  • --wbr-shadow — kolor twardego „rzucanego” cienia.
  • --wbr-radius — zaokrąglenie rogów (domyślnie 3px).
  • --wbr-pad-y, --wbr-pad-x — wewnętrzne odstępy.
  • --wbr-gap — odstęp między linkami nawigacji.
  • --wbr-font — krój pisma (dobierz taki sam jak na reszcie strony).
  • --wbr-font-size — rozmiar tekstu (domyślnie 14px).
  • --wbr-logo-size — wysokość logo marki (domyślnie 18px).

CSS Shadow Parts

Widget wystawia tak zwane shadow parts — możesz ostylować każdy element po nazwie, np.:

git-webring::part(box)    { border-style: dashed; border-radius: 0; }
git-webring::part(link)   { font-weight: 600; }
git-webring::part(status) { text-transform: uppercase; letter-spacing: .04em; font-size: 11px; }
git-webring::part(list)   { display: none; }   /* ukryj listę wszystkich członków */

Dostępne części: box, logo, bar, title, help, row, link, sep, status, list, summary.

Dzięki temu możesz np. ukryć listę wszystkich członków, zmienić znak separatora między linkami albo wymusić konkretną czcionkę tylko dla nawigacji — bez modyfikowania samego widgetu.

Projekt hostowany jest jak zwykłe repozytorium git. Zrób fork, edytuj members.json, wyślij pull request.
